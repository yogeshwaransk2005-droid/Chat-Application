# Chat Application

Real-time chat application built with:

- React.js
- Spring Boot
- MongoDB Atlas
- JWT Authentication
- WebSocket (STOMP + SockJS)
- Vercel Deployment
- Render Deployment

## Features

- User Registration & Login
- JWT Authentication
- Real-time Messaging
- Online User Status
- Private Chat
- Profile Pictures
- Responsive UI

Frontend: React, Axios, Context API  
Backend: Spring Boot, Spring Security, WebSocket
